# 投擲物重繪需求

目前有 5 種投擲物還是原版外觀。請照下面的規格畫，畫好後放回 `drafts/` 資料夾，檔名不變，再跟我說，我會接進遊戲。
（幽匿方塊已經換成專屬的 3D 模型，不用畫。）

總覽圖是 `sheet.png`：
- 左：目前的原版外觀
- 中：底稿版面，灰色是要畫的區域
- 右：丟它的生物的配色

## 共通規則
- 背景透明；可以用半透明，但盡量是不透明的像素風。
- 尺寸照底稿，不要改。
- **不要拿原版貼圖來改。** 底稿只標出區域，不含原版像素，這樣成品才能和模組一起發布。
- 發光的部分用接近白的亮色，例如亮青、亮粉。遊戲裡可以讓這些部分在暗處發光。

## 1. 尖刺飛鏢 `sift_dart.png`（32×32，箭矢版面）
- **誰丟**：Dartback（背刺）、Prickle（尖刺環）
- **版面**：和原版箭一樣。
  - 上方 32×5 是側面：箭頭在左、尾端在右，中間一排是箭身。
  - 左下 10×5 是尾端十字截面。
- **建議**：不要畫成木頭箭桿加羽毛，改成生物身上拔下來的骨刺、晶刺，配色用 Dartback 的紫紅 `#704060` `#C05090`，尖端可以帶 Prickle 的淡紫 `#B0A0D0`。

## 2. 獵人標槍 `hunter_javelin.png`（32×32，三叉戟版面）
- **誰丟**：Hunter
- **版面**：和原版三叉戟一樣。
  - 左邊 12×32 是長桿、槍頭各面的展開。
  - 右邊 x19–23 是側面剪影。
- **建議**：
  - 槍頭只要一支尖頭，不要三叉。槍頭發青光 `#30C0C0`，靠近槍頭的桿身用 Hunter 的橘色 `#E07030` 纏繞布條，其餘是深藍黑桿 `#102040`。
  - 和 Hunter 模型手上那支標槍一致：青色槍尖、橘色纏條。
  - 我會改用標槍專屬的 3D 模型。三叉戟的三根叉會變成一根，所以叉尖那一塊只要畫中間那根；兩側的叉可以留空，我會調整模型。

## 3. 投石 `hurler_rock.png`（16×16，物品圖示）
- **誰丟**：Hurler
- **建議**：一顆圓圓的碎岩塊，不要像鵝卵石方塊。配色接近 Hurler 本體的淡紫灰 `#B0B0D0` `#A0A0C0`，加暗紅 `#604040` 的裂縫或泥塊。
- **顯示方式**：遊戲裡以平面圖示（永遠面向鏡頭）、放大約 1 倍顯示。

## 4. 君王羽刃 `monarch_feather.png`（16×16，物品圖示）
- **誰丟**：Monarch（懸停後射出）
- **建議**：一片銳利的羽刃。用 Monarch 的深紫黑 `#302030` `#605070`，邊緣是淡紫藍 `#607080` 的亮邊，刃尖帶一點發光。斜放，方向和原版羽毛一樣，從左下往右上。
- **顯示方式**：遊戲裡放大 1.5 倍，而且會在暗處發亮。

## 5. 陷阱師的網 `trapper_net.png`（16×16，物品圖示）
- **誰丟**：Trapper
- **建議**：粉紫色的靈魂網。網線用 Trapper 的亮粉 `#F080C0` `#D05090`，節點是深紫 `#302050`，中間可以有一個發光的結。不要畫成原版蜘蛛網那種白色放射狀。
- **顯示方式**：遊戲裡放大 1.6 倍。
