# 生物材質升級與氣候變體要求書

整理自使用者 2026-11-24 的要求。標「待確認」的是我提出、使用者還沒同意的項目。

---

## 一、材質升級

### 1. 範圍
- **全部**生物原始材質都要升級，共 33 張：
  - 動物、小動物、怪物、Boss
  - Blub 系列
  - Sculk 系列
  - Echo Golem、Sift Warden
- 不在範圍內的：
  - 船、坐墊、裝飾陶罐、裝備、投射物、界伏蚌（`mob_texture_record.py` 的 `SKIP_DIRS`）
  - 只畫發光點的發光層（`_glowmask`、Sift Warden 的三張發光層）。它們要跟本體對齊，不另外升級。

### 2. 畫之前
1. **先找色盤**：記下每種材質目前的固有色、亮部和暗部。
2. **再找現實參考**：每隻生物要寫出它的毛、皮膚、甲殼或植物部分對應現實中的什麼，並依那個質感畫紋理。
   | 材質 | 現實參考 | 畫法 |
   | :-- | :-- | :-- |
   | 毛 | 羊毛、長毛牛 | 2×2~3×3 的捲毛簇，左上亮、右下暗，簇間留深縫；長毛畫成直向一絡一絡，毛尖較亮 |
   | 皮膚 | 兩棲類、犀牛皮 | 不規則斑塊與皺褶線；腹側亮、背側暗並帶斑點 |
   | 甲殼、角質 | 甲蟲殼、穿山甲鱗 | 一片片甲板，上緣亮邊、下緣陰影；尖刺從根部暗到尖端亮 |
   | 果凍 | 水母、果凍 | 中心亮、邊緣深且較飽和；1~2 格反光點、內部氣泡點 |
   | 植物 | 樹皮、苔蘚、葉脈 | 樹皮直向裂紋、苔蘚細碎綠簇、葉面葉脈 |
   | 幽匿組織 | 原版幽匿方塊、深海組織 | 深色底上的網狀亮脈絡與冷色斑點；發光處不動 |
   | 石頭 | 凝灰岩 | 岩塊、裂縫、風化亮邊 |
3. 依 `minecraft-texture-crafter` 的原則上色：
   - 色相偏移：亮部往暖、暗部往冷。
   - 不用純黑 `#000000` 和純白 `#FFFFFF`。
   - 用像素簇表現明暗，不用單點雜訊或棋盤格。
   - 光源在左上。

### 3. 畫的時候
- **增加色彩過渡**：同一種材質要有多階漸層，**不能有單一顏色平塗的大片區域**。
- **不能過度跳色**：相鄰像素的明度差不能突然變大。
- **升級要看得出來**：
  - 2026-11-24 第一版平均每像素只改了 4~16/255，使用者判定為「沒有升級」。
  - （待確認）目標：平均 RGB 變化 ≥ 20/255，且至少 30% 的像素變化 ≥ 24/255。
- 色盤誤差（下面的第 5 點）只看**每種材質的平均色**。所以材質內部的明暗可以拉開到約 ±25~35%，用來畫出紋理。
- **UV 與透明輪廓不能動**：模型的 UV 位置固定。只有 Nuzzle 例外，它補了殼頂缺毛的部分，並清掉沒用到的區域。
- **眼睛、嘴、4 px 以下的小面、發光色不動**，除非使用者另外指定。
- 有 `_glowmask` 的貼圖，遮罩底下的像素保留原色，發光層才能對齊。

### 4. 記錄與備份
- **升級前完整記錄原檔**：
  - 位置：`.texture_backups/20261124_mob_originals/`。
  - 內容：`manifest.json`（大小、sha1、色盤、HSV、明度）加上原檔、模型與動畫。
- 五隻暫代生物（Nester、Pollinator、Seedling、Sprout、Sentinel）的基準，是**原本共用圖集依各自模型拆出來的圖**（`.texture_backups/20261124_placeholder_split/`），不是舊的暫代圖。
- 不刪除任何現有 PNG（貼圖凍結規則）。用不到的舊圖由使用者自己刪。

### 5. 驗收（每一隻都要經過子代理）
由**另一個子代理**比對原檔與升級後的檔案，跟方塊、物品的檢查方式一樣：

| 項目 | 標準 |
| :-- | :-- |
| 色盤誤差 | 每種材質（依色相分群）的平均色與原檔相比 ≤ 10% |
| 過度跳色 | 新增的硬跳（明度差 > 0.18，且比原檔同位置多 0.06 以上）≤ 3 處或 1% |
| 柔和過渡 | 異色相鄰中，明度差 < 0.10 的佔比 ≥ 20% |
| 平塗 | 單一顏色不能佔掉一大片（第一版 Sculk Monstrosity 有 46% 是同一色，不合格） |
| 輪廓 | 透明遮罩與原檔相同 |
| 看得出升級 | （待確認）平均變化 ≥ 20/255 |
| 外觀 | 子代理要看放大的對照圖與 3D 預覽，不能只看數字 |

工具：`python -I tools/texture_pipeline/mob_texture_record.py compare <快照資料夾> [名稱]`

### 6. 流程
1. 一次做一隻：產出「原檔｜升級後」的對照圖與遊戲內截圖，經子代理確認後再做下一隻。
2. 有氣候變體的生物，一般版、熱帶版、寒帶版三張一起做、一起審。
3. 使用者說「其他比較沒問題直接接著做完」之後，可以連續做；有問題的才停下來問。

## 二、熱帶與寒帶變體

### 1. 哪些生物有變體（12 隻）
| 分類 | 生物 |
| :-- | :-- |
| 動物 | Nuzzle、Lootkin、Slabber、Pollinator |
| 小型動物 | Prickle、Dartback、Fusefly、Wobble |
| 原本的暫代生物 | Nester、Seedling、Sprout、Sentinel（Pollinator 已列在動物） |
| **排除** | Blub（使用者指定） |

### 2. 怎麼決定是哪一種
- 依**生態域溫度**決定。生物第一次載入世界時判定，結果存在實體上，之後不會再變。
- 隙浮維度：
  - 溫度 ≥ 1.4 是熱帶：琥珀沙丘、赤紅峽谷、靈魂火山口、靈液深淵、搖籃曲山丘。
  - 溫度 ≤ 0.7 是寒帶：紫晶深板岩區、枯萎窪地、柳絮林地。
- 其他維度：溫度 ≥ 0.95 是熱帶，≤ 0.3 是寒帶。
- 程式：`entity/ClimateVariant.java`。

### 3. 外觀要求
| | 熱帶 | 寒帶 |
| :-- | :-- | :-- |
| 毛 | **較少**（毛較短、露出較多皮膚） | **較多**（毛領、毛袖、蓬鬆毛球等） |
| 花 | **身上有明顯的花** | 沒有花 |
| 顏色 | **較鮮豔**（飽和度較高） | **較冷**（往藍、紫偏；白毛帶一點藍灰） |

- 寒帶要**量得出比一般版冷**：藍減紅（B−R）的平均值要高於一般版。
- 熱帶要量得出比一般版鮮豔：平均飽和度要高於一般版。

### 4. 模型要求
- 變體要**加模型部件**，不能只換顏色。例如寒帶加毛，熱帶加花和葉。
- **所有花都要做成立體的**，不能平面和立體混用，也不能只畫在貼圖上。
- 花瓣和毛部件的每一面都要**不透明**，不能有挖空的缺角。
- 背上的薄片要改成小型立體部件。例如 Wobble 熱帶用小蓮花加葉，Slabber 熱帶用垂下的小葉。
- 變體模型的骨骼要跟原模型相同，才能共用動畫：
  - 檔名：`<生物>_tropical.geo.json`、`<生物>_cold.geo.json`。
  - 產生工具：`tools/models/build_<生物>_variants.py`、`build_placeholder_variants.py`。
- 新部件的 UV 只能放在貼圖沒用到的空白處。

### 5. 每隻生物的檔案
- 一般版：`<生物>.png`
- 熱帶版：`<生物>_tropical.png` 加上 `<生物>_tropical.geo.json`
- 寒帶版：`<生物>_cold.png` 加上 `<生物>_cold.geo.json`
- 變體貼圖同樣要遵守第一部分的材質規則與驗收標準，並跟一般版一起審查。

## 三、個別生物的指定要求

### Nuzzle
- **眼睛**：黑色在外、淡綠在內，**往內看**。
  - 貼圖：(3,2) 淡綠、(3,3) 近黑。
  - 眼睛方塊往內移 1 px。
- **殼頂後方缺毛**：是 UV 的問題，已補上。
- **寒帶**：
  - **上方不要多一層**。
  - 加一個**像兔子的圓形尾巴**。
  - 臉周圍有毛領，腳上有毛袖。
- **熱帶**：6 朵立體扶桑花（背上 2 朵，左右各 2 朵）。
- **剃毛與染色**：跟原版羊一樣。
  - 剪刀剃毛會掉 1~3 個羊毛。沒染色掉紅羊毛，染過色掉該色羊毛。
  - 毛會在 2400~4800 tick 後長回來。
  - 染料可以改毛色。

### 五隻原本的暫代生物（Nester、Pollinator、Seedling、Sprout、Sentinel）
- 要**用原本的共用圖片依各自的模型拆成獨立貼圖**，不能重畫成別的樣子。
- 拆出來之後要能依氣候做熱帶和寒帶的變化。
