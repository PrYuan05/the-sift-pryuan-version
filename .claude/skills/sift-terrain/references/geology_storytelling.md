# 地質演化與環境敘事（參考筆記）

來源：廢土貓大 LogoCat〈一鍵模擬 ... 連地圖都不用蓋了 ...〉（YouTube `EQanB12XCBU`，2026-10），
介紹 Lirsty 的 Minecraft 地質模擬器。以下是摘要與套用到 The Sift 的做法，不是逐字稿。

## 影片重點
1. **AI 地形「沒有靈魂」**：直接刷地形、或搬真實高度圖，都缺少「時間演化」的痕跡。
   好地形看得出它是怎麼形成的（Kenshi 的 30×30 公里地圖疑似用地質模擬軟體先跑出河流、峽谷再烘焙）。
2. **用規則推演，而不是一格一格擺**：給初始狀態＋物理規則（侵蝕、摩擦、抗侵蝕度、礦物生成、乾濕循環、
   植物生長），跑幾千步，讓河流、沖積、淤積自己長出來。例：6000 步、15 個乾濕循環沖出全圖河道。
3. **決定性、可溯源**：隨機數用種子＋雜湊，同種子每次結果相同；每個方塊都能反查「它經歷了什麼」。
4. **事件推演**：水庫潰壩、隕石撞擊、魔法石吸乾水分、沙塵暴、酸雨、石油雨、金屬鏽蝕。
   每種方塊對事件有自己的反應（木頭、石頭、土壤怎麼變）。
   - 沙塵暴：依風向，沙子淤積在牆角與女兒牆的背風側（像久沒掃的地板角落）。
   - 酸雨／雨水碰到鏽蝕金屬：牆面留下鏽痕。
5. **黑暗靈魂式環境敘事**：不直接說明，只留下可被推敲的痕跡。
   例：黑色沙漠上有油井 → 玩家推理出這是焦油砂；圓滾滾的大石頭裡挖出紫色魔法石核心 → 推理出一千年前的魔法隕石被潰壩沖散。
   **地編師要能解釋每個痕跡的來歷**，玩家越調查越覺得合理。
6. **分工**：人決定故事與世界觀，AI 負責大量參數（幾千種方塊的物理反應）與加速；模擬本身是決定性的程式，不是生成式亂生。
7. **時光快進**：把一代地圖快轉一千年（旱災、隕石、魔法裂隙），直接得到二代地圖。

## 套用到 The Sift（我們用的是密度函數＋地表規則，沒有逐步模擬）
先替每個生態域寫一段「形成史」，再讓每個地形與材質都能從那段歷史推出來：

| 影片的做法 | 在 build_the_sift.py 裡怎麼近似 |
| :-- | :-- |
| 侵蝕沖出河道 | `abs(noise)` 的谷網（裂谷、搖籃曲峽谷）；谷底低於 63 自動填靈液 |
| 沖積扇、淤積 | 谷口與谷底用 `blended_bands` 依離谷中心的距離換成較細的材質（礫 → 沙 → 泥） |
| 抗侵蝕度不同的岩層 | 硬岩做平台與帽岩（`capped_*`），軟岩做緩坡與谷壁；高度樣條的平台＝硬層 |
| 背風側淤積（沙塵暴） | 地表規則讀一個「風向」雜訊或用 `minecraft:steep` 區分陡坡，把沙／灰燼放在一側；地物可沿固定方向偏移 |
| 事件留下的材質梯度 | 依離事件中心的距離（同一個雜訊或 ridges）做材質帶：越近越焦、越紅 |
| 魔法石核心的圓石 | 地物：大圓石（`StrataSpireFeature` 類）內部放 `soul_crystal_block`，散落在事件下游 |
| 可溯源 | 所有材質帶與地形讀同一個雜訊、同一組門檻常數（`SOUL_RIFT_*`、`CONE_START` 等），改一處兩邊一起變 |

### 例：靈魂火山高原 `soul_caldera` 的形成史（草稿，待使用者確認）
- 火山噴出的不是岩漿而是靈魂（靈液）→ 火山口湖與裂谷底的靈液。
- 靈液流過的地方岩石被「燒」成紫紅（`magma_vein_slate` → `crimson_capped_void_stone` → `red_sculk_vein_bottom`），越靠近靈液越紅。
- 冷卻後的熔岩原是灰黑的虛黑岩；火山錐上越高越熱（鏽色火山渣 → 灰燼 → 餘燼石）。
- 可加的痕跡：灰燼只落在火山的一側（盛行風）；裂谷下游的沖積扇；散落在下游、內含靈魂晶塊的圓石（噴發時被拋出的「靈魂火山彈」）。
